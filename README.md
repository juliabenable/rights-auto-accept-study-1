# Yes in Advance

Study of the creator side of brand content-rights offers, built like Airbnb Instant Book. Oct 20, 2026.

- `index.html`: the study (v0 by text, history, the Airbnb flow in short, 16 platforms, range of ideas, the recommended shape, decisions).
- `airbnb-flow.html`: Airbnb Instant Book start to finish, 24 dated images.
- `prototype.html`: clickable creator-app prototype. The dark panel switches scenarios.

Pages are self-contained (images embedded). Everything on the creator side is proposed, not decided.
